# FactoryPick 프론트엔드

## 카테고리 아이콘

`src/lib/categoryIcons.js`에 업종 29종, 기존 식품 분류 3종, 전체·미분류 SVG를 정의합니다.
필터·공장 상세·카테고리 통계·지도에서 같은 그림과 색을 사용합니다.
지도는 [Kakao CustomOverlay](https://apis.map.kakao.com/web/sample/customOverlay1/)로 40px 원형 아이콘을 표시합니다.
현재 선택한 카테고리를 우선하고, 전체 보기에서는 응답 카테고리 중 첫 번째 지원 아이콘을 사용합니다.
알 수 없는 사용자 지정 분류와 미분류에는 회색 공장 아이콘을 사용합니다.

백엔드의 `category-schema.sql` 적용 및 서버 재시작이 필요합니다. `npm test`, `npm run lint`, `npm run build`로 검증합니다.

React + Vite로 만든 공장·제품 조회 대시보드입니다. 참고 이미지의 어두운 화면 구성을 사용하며 모든 수치는 backend API에서 읽습니다.

## 실행

1. 로컬 MySQL과 backend를 실행합니다 (`backend` 폴더에서 `./gradlew.bat bootRun`).
2. `frontend` 폴더에서 최초 1회 `npm ci`를 실행합니다.
3. `.env`에 `VITE_KAKAO_JAVASCRIPT_KEY`를 입력합니다. 카카오 JavaScript SDK 도메인에 `http://localhost:5173`을 등록합니다.
4. `npm run dev` 후 http://localhost:5173 에 접속합니다.

개발 중 /api 요청은 localhost:8080으로 프록시됩니다. 지도 키가 없어도 검색·목록·상세·통계는 사용할 수 있습니다. 지도 영역에는 설정 안내가 표시됩니다.
운영 배포에서는 /api 경로를 Spring 서버로 프록시해야 합니다.

## 화면

- 지도: 카테고리 클릭 즉시 공장 검색과 지도에 동일 조건 적용. 지역·시군구·공장/기업/주소·생산제품 복합 검색. 카테고리 아이콘 선택 시 우측 공장 상세 표시.
- 공장 목록: 페이지 조회, 상세 확인, 지도 이동.
- 제품 목록: 카테고리·제품명 검색, 제품 상세와 생산 공장 목록.
- 통계: 전체 DB 기준 카테고리별·지역별·제품별 공장 수. 복수 카테고리 공장은 각 분류에 중복 집계되므로 분류별 합계는 전체 공장 수와 다를 수 있습니다.
- 데이터 관리: 관리자 로그인/로그아웃, 공장·제품 등록/수정/삭제, 공장별 생산제품 연결, CSV 업로드 및 결과·이력. 좌표 없는 공장의 상세에서 주소→좌표 변환 실행 가능.

관리자 세션은 현재 브라우저 탭의 sessionStorage에 유지되며 토큰 만료·401 응답 시 해제됩니다.
카카오 REST API 키는 backend/.env에서만 설정합니다. 자세한 설정은 ../backend/KAKAO.md를 참고하세요.

## 표시 범위

실제 DB의 대표 업종코드와 기존 제품 분류를 사용하며, 공장이 연결된 카테고리만 필터에 표시합니다.
매출, 생산량, 가동률, 불량률, 제품/공장 사진, 알림, 리포트 기능은 해당 데이터/API가 없어 넣지 않았습니다.
공장 규모는 상세에서 확인·관리할 수 있지만 backend 검색 조건이 아니므로 필터에서는 제외합니다.
지도는 카테고리별 SVG 아이콘을 사용하며, 좌표가 없는 공장은 목록에만 나타납니다.
현재 영역의 좌표 있는 공장을 10,000개 제한 없이 조회합니다. 먼저 같은 도로명·건물번호의 주소를 층·호수와 무관하게 묶고, 그 묶음들을 화면상 약 64px 이내에서 합칩니다. 건물번호(부번 포함)가 다르면 확대 시 분리됩니다. 도로명 주소로 해석할 수 없으면 원문 주소를 사용하며, 주소가 없으면 같은 좌표만 먼저 묶습니다.
묶음은 카테고리 아이콘 옆에 정확한 공장 수를 표시합니다. 카테고리가 섞이면 상위 2개 아이콘을 함께 표시하고, 마우스를 올리면 분류별 개수를 보여줍니다.
묶음을 클릭하면 2단계 확대하며, 하나의 주소로 묶였거나 같은 좌표이거나 최대 확대에서도 겹치면 페이지당 20개씩 공장 선택 목록을 엽니다. 아이콘 툴팁에는 주소를, 선택 목록에는 각 공장의 상세주소를 표시합니다. 지도 API의 `address` 필드를 사용하므로 백엔드도 재시작해야 합니다.
필터·이동·확대 변경 시 현재 화면 기준으로 다시 묶습니다. 표시 중인 공장 수는 묶음 수가 아닌 공장 수입니다.
